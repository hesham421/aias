# ADR-REG-009 — Connections come from the environment's activation configuration at start-up; REG stores a credential reference, never a secret
Status      : ACCEPTED
Stage       : P1        Module: REG        Version: v1
Context     : US-REG-009 and US-REG-010 require each connection to be defined once, outside the service packages, and set per environment at activation; US-REG-011 requires a read-only database user. The raw idea §4 shows a connection as `name`, `type`, `endpoint`, `query_tool`, `dialect` and leaves credentials unstated. No upstream text says where the activation configuration lives, whether REG stores it, or how the read-only property is known to the service.
Decision    : Each environment carries an activation configuration (an environment setting, like the package directory of ADR-REG-007) listing its connections. Every start of the service in that environment is its activation: REG registers each listed connection, updates one whose settings changed, and removes one no longer listed — service packages are never touched. A connection holds name, type (`mcp` | `jdbc`), endpoint, query tool (mcp), dialect, environment name, a read-only declaration, a limited-to-views declaration and a credential reference: the name under which the environment's secret store holds the credential. REG never stores the credential itself. The service administrator declares the database user read-only in the activation configuration; a connection without that declaration is refused and reported (raw idea §12). The read-only property itself is enforced at the database user (D2); REG's refusal is the configuration-side guard. Best practice followed: externalised, per-environment configuration with secrets referenced, never persisted.
Consequences: P2 stores connections without any secret column. P3.1 exposes no HTTP operation on connections; CHK and DOC read them in-process. A current service package version whose query names a connection that the environment does not register is refused to Checks until the connection is activated.
