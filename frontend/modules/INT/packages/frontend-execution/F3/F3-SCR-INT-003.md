### F3 — SCR-INT-003 Document upload
- `uploadFormSchema` — documentType: required, one of REQUIRED-TYPES-QUERY's `requiredDocumentTypes` (REQ-INT-016); file: required, exactly one file (UploadRequest of API-INT-002). No client size limit (the server decides — REQ-INT-013, REQ-INT-014).
- Server refusals bound to controls: `DOC-422-DOCUMENT-TYPE-NOT-OF-SERVICE` → inline on documentType; `INT-413-UPLOAD-TOO-LARGE`, `DOC-400-INCOMPLETE-UPLOAD` → inline on file; `INT-409-CHECK-NOT-AWAITING-DOCUMENTS`, `DOC-409-CHECK-ENDED`, `DOC-422-UPLOAD-LIMIT-REACHED` → form message (texts bound in §3.0). A type already uploaded stays a valid choice (REQ-INT-065).
- One submit ("Upload"); the confirmation is never part of this form (REQ-INT-019).
