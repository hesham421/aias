# ADR-INT-010 — The checks INT runs before an Approval API call refuse with the Report Store's own codes and messages; without an Approval API call INT hands the decision straight to the Report Store and passes its refusal through
Status      : ACCEPTED
Stage       : P1        Module: INT        Version: v1
Context     : The Report Store refuses an incomplete decision, a decision on a Check that is not COMPLETED and a second decision (CON-RPT-006: RULE-RPT-011, RULE-RPT-012, RULE-RPT-013). ADR-INT-004 requires the Approval API never to be called for a decision the Report Store would refuse, so INT must evaluate those same conditions itself before the call — from the decision request and the Check read (CON-RPT-003). ADR-INT-003 gives INT codes only for what INT itself decides; these conditions are the Report Store's rules, evaluated early.
Decision    : (1) Where an APPROVED decision would be executed through the Approval API, INT refuses before the call: a decision code outside EMPLOYEE_DECISION or a missing deciding employee → `RPT-400-DECISION-INCOMPLETE`; a Check that is not COMPLETED → `RPT-409-CHECK-NOT-COMPLETED`; a Check that already holds a decision → `RPT-409-DECISION-ALREADY-RECORDED`; an unknown Check → `RPT-404-CHECK-NOT-FOUND` — each with the Report Store's message text (RULE-INT-002, RULE-INT-003). (2) Where no Approval API call is made (REJECTED, or a version that does not enable it), INT does not repeat these checks: it hands the decision to the Report Store, which refuses with the same codes. The caller therefore sees one code per situation whichever step detected it. (3) The upload refusal for a Check not waiting for documents stays INT's own code `INT-409-CHECK-NOT-AWAITING-DOCUMENTS` (ADR-INT-003, ADR-INT-005), because Document Access has no such rule.
Consequences: No INT code duplicates a Report Store refusal. P3.1 lists the four RPT codes in INT's error catalog as pass-through rows owned by RPT, raised early by INT on the approval path. If RPT changes a message, INT follows the RPT contract.
