# ADR-DOC-005 — DOC states every raw-idea §12 guardrail at the surface it controls
Status      : ACCEPTED
Stage       : P1        Module: DOC        Version: v1
Context     : Profile check AIAS-1 requires every guardrail of raw-idea §12 to be a REQ with at least one AC, and the owner made the §12 guardrails mandatory requirements of this version (A2). DOC runs the document source query, opens host files, reads host BLOB columns, holds manual uploads and calls the document-reading model, so most guardrails act inside DOC; two of them (the LLM never writes SQL or triggers approval; approval only on the employee's action) act mainly in CHK and INT. ADR-REG-008 left the Check-time enforcement of guardrails 1, 2, 5, 6, 7 and 8 to the owning modules.
Decision    : Every §12 guardrail gets a DOC requirement at the surface DOC controls, traced to the DOC story it serves: (1) the LLM analyses only → the document-reading model is given no tool (REQ-DOC-048); (2) approval only on the employee's action → DOC calls no host endpoint, the Approval API included (REQ-DOC-053); (3) read-only host access → host files opened for reading only, never written, moved or deleted, and no document source query run over a connection not declared read-only (REQ-DOC-049, REQ-DOC-050, REQ-DOC-052); (4) bound parameters, no SQL from free text → the document source query runs exactly as written with the request number bound as its only parameter (REQ-DOC-004, REQ-DOC-012, REQ-DOC-051); (5) paths inside the storage root → REQ-DOC-008 … REQ-DOC-011; (6) nothing skipped silently → one outcome per document with a reason for every UNREADABLE one, and one failure never stops the others (REQ-DOC-034 … REQ-DOC-037); (7) document content is data → REQ-DOC-045 … REQ-DOC-047; (8) per-Check limits → maximum rows (REQ-DOC-039), timeout (REQ-DOC-040), maximum file size (REQ-DOC-042, REQ-DOC-043); (9) nothing carried between Checks → REQ-DOC-054 … REQ-DOC-057.
Consequences: CHK and INT still carry their own enforcement of guardrails 1 and 2; DOC's requirements make sure DOC can never be the path around them. P3.1 review (AIAS-3..AIAS-8) scores the enforcement where it runs.
