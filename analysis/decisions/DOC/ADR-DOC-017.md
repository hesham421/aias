# ADR-DOC-017 — DOC publishes an in-process operation that lists the Uploaded Documents of a Check without content; its HTTP read delegates to it
Status      : ACCEPTED
Stage       : P1        Module: DOC        Version: v1
Context     : INT is the single REST surface of the employee frontend (ADR-INT-020) and serves every read in-process through the owner's published contract. DOC's contract had only the handover, the fetch and the end of a Check (CON-DOC-003 … CON-DOC-005); the list of a Check's uploads existed only as the HTTP read API-DOC-001, with no requirement of its own. INT recorded the gap (ADR-INT-020 (4), API-INT-007 adapter PENDING) and asked DOC to close it in this revise.
Decision    : (a) A new requirement REQ-DOC-064 states the list: for one Check, every Uploaded Document carrying that Check's identifier, ordered by upload time, with its identifier, document type, file name, file size, oversized flag and upload time — never its content. (b) The contract publishes it as the in-process operation CON-DOC-006 `listUploadedDocuments(checkId)` for INT (API-INT-007 binds to it); an unknown or ended Check answers an empty list, not an error. (c) DOC holds no read status for an upload — reading happens only inside the fetch and the outcome is stored by RPT (ADR-REG-001); the oversized flag is the only reading-related fact DOC can give (an oversized upload will be UNREADABLE / TOO_LARGE). A caller wanting read statuses takes them from RPT's Check Documents. (d) P3.1 implements it once in the service layer; the HTTP read API-DOC-001 delegates to the same service and keeps its path and answer.
Alternatives rejected: INT reading DOC_UPLOADED_DOC directly — the entity is PRIVATE (ADR-DOC-003); INT calling DOC's HTTP read — one deployable, in-process interface per profile; adding a read status to the Uploaded Document — DOC would duplicate RPT's record (ADR-REG-001).
Consequences: Contract gains one ADDITIVE item (CON-DOC-006); no table changes; INT's ADR-INT-020 gap (4) can be closed by INT. P4 adds test cases for AC-DOC-069 and AC-DOC-070.
traces      : US-DOC-005, POL-DOC-007, REQ-DOC-064, ENT-DOC-001
