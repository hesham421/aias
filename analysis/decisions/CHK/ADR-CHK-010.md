# ADR-CHK-010 — The environment data class is one platform configuration value read by both DOC and CHK; the comparison model tier is part of CHK's comparison model configuration
Status      : ACCEPTED
Stage       : P1        Module: CHK        Version: v1
Context     : ADR-CHK-006 enforces the free-tier rule (G13) from the comparison model's tier and the environment's data class, "the same facts DOC uses", and leaves P1 to place the data class so both modules read one value. ADR-DOC-009 introduced the data class (SYNTHETIC or REAL, REAL when not declared) as "the environment's document access setting". A second, CHK-owned data class setting could disagree with DOC's and let real data reach a free-tier model through one of the two paths.
Decision    : (1) The environment data class (SYNTHETIC or REAL; REAL when not declared) is ONE platform configuration value, held beside the per-Check limits of ADR-REG-006 (Check timeout, maximum rows, maximum file size, upload window), and read by both DOC and CHK; CHK defines no setting of its own for it. (2) The comparison model configuration declares the comparison model's provider, model identifier and tier (FREE or APPROVED; FREE when not declared); the tier is CHK's, separate from the document-reading model tier of ADR-DOC-009. (3) While the comparison model tier is FREE and the data class is REAL, CHK sends nothing to the comparison model and the Check ends FAILED with reason MODEL_NOT_PERMITTED (ADR-CHK-006). Neither value is an entity.
Alignment   : ADR-DOC-009's "environment's document access setting" names the same single value; DOC's behaviour is unchanged (non-breaking). DOC's next version should cite it as platform configuration (recorded for DOC); the platform configuration document of P3.1 lists it once.
Alternatives rejected: a CHK-owned data class setting — two values for one fact; deriving the data class from the comparison model tier — the tier says nothing about the data.
Consequences: Switching an environment to REAL data or a model to APPROVED is configuration only (D3). Tests set SYNTHETIC in the test environment.
