# ADR-DOC-016 — The number of Uploaded Documents per Check is capped by the platform configuration `maximum uploads per Check` (default 20)
Status      : ACCEPTED
Stage       : P1        Module: DOC        Version: v1
Context     : Nothing bounded how many Uploaded Documents may be handed over for one Check in `manual` mode: RULE-DOC-003 rejects only an incomplete upload, and the maximum file size (POL-DOC-012) bounds one file, not their number. A faulty or abusive caller could grow DOC's store of file content without limit for a single Check. Raw-idea §12 guardrail 8 says "each check has limits" and ADR-REG-006 makes such limits platform configuration; no owner value for an upload count exists. (Analysis-gate finding G3.)
Decision    : (a) A per-Check limit "maximum uploads per Check" is platform configuration, alongside the timeout, maximum rows and maximum file size (ADR-REG-006). Best-practice default: 20 — ten times the two required document types of the pilot service, room for corrections (each correction is a new upload, ADR-DOC-006) while keeping one Check's stored content bounded at 20 × the maximum file size. (b) A handover for a Check that already holds that many Uploaded Documents is rejected with the RULE-DOC-010 message and nothing is stored (REQ-DOC-063); oversized uploads count, since each is a row. (c) The count is taken from the committed Uploaded Documents of the Check at handover time; concurrent handovers for one Check can exceed the limit by at most the number running at once, which INT's one-file-per-request upload keeps to a single extra row.
Alternatives rejected: one upload per required document type — forbids the corrections ADR-DOC-006 allows; a fixed limit in code — the limits are platform configuration (ADR-REG-006); no limit — leaves guardrail 8 open for uploads.
Consequences: P3.1 adds the configuration key `aias.check.max-uploads` (default 20) to the CORE per-Check limits and the in-process code `DOC-422-UPLOAD-LIMIT-REACHED`; INT shows the message. The value can be changed by configuration alone.
