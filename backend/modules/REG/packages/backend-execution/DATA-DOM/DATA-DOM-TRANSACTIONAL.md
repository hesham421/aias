- RULE-REG-028 — Load Result text shortened · trigger: on load and on activation · scope: CREATE (load run)
  - statement: The system shall shorten the subject name, service code and reason of a Load Result to 200, 100 and 1000 characters, replacing the last kept character with "…" when shortened.
  - message (en): none — the stored text is shortened; nothing is refused · message (ar): not applicable
