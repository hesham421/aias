# ADR-CHK-009 — CHK states every raw-idea §12 guardrail at the surface it controls
Status      : ACCEPTED
Stage       : P1        Module: CHK        Version: v1
Context     : Profile check AIAS-1 requires every guardrail of raw-idea §12 to be a REQ with at least one AC; the owner kept the §12 guardrails in this version (A2). CHK runs the service queries, calls the comparison model, decides the findings and the Overall Status, and ends every Check, so most guardrails act inside CHK. Guardrail 5 (storage root) and the maximum file size of guardrail 8 act inside DOC (ADR-DOC-005), guardrail 2's approval call inside INT. ADR-REG-008 left the Check-time enforcement to the module that runs it.
Decision    : Every §12 guardrail gets a CHK requirement at the surface CHK controls: (1) the LLM analyses only → no tool on the comparison model, nothing in its output executed (REQ-CHK-030, REQ-CHK-031); (2) approval only on the employee's action → CHK never calls the Approval API, never reads its definition, never records an Employee Decision (REQ-CHK-032, REQ-CHK-033); (3) read-only host access → service queries only through the platform MCP query channel over connections declared read-only (REQ-CHK-013, REQ-CHK-014); (4) bound parameters → the request number only as the bound input parameter, SQL text unaltered (REQ-CHK-011, REQ-CHK-012); (5) storage root → CHK opens no host file, BLOB column or upload itself, so DOC's storage-root check cannot be bypassed (REQ-CHK-018); (6) nothing skipped silently → unread queries and unread required documents appear in the report and block COMPLIANT (REQ-CHK-022, REQ-CHK-049, REQ-CHK-050); (7) content is data → REQ-CHK-034 … REQ-CHK-036; (8) per-Check limits → maximum rows and remaining time on every query call, Check timeout (REQ-CHK-016, REQ-CHK-051), maximum file size through DOC only (REQ-CHK-018); (9) nothing carried between Checks → REQ-CHK-063 … REQ-CHK-066.
Alternatives rejected: leaving guardrails 5 and 8 (file size) to DOC without a CHK requirement — CHK could then become a second way to documents.
Consequences: P3.1 review (AIAS-3..AIAS-8) scores the enforcement where it runs; INT still carries the Employee Decision path.
