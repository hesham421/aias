# ADR-INT-022 — INT's test plans after the read operations: AC-INT-067 … AC-INT-074 are backend cases TC-INT-087 … TC-INT-094 on the SVC-API-QUERY package; the write cases move to SVC-API-COMMAND; frontend cases run against api-spec-int.yaml alone; supersedes ADR-INT-019 (1) counts and (5) mock part
Status      : ACCEPTED
Stage       : P4        Module: INT        Version: v1
Context     : ADR-INT-020 added REQ-INT-061 … REQ-INT-064 (AC-INT-067 … AC-INT-074) and API-INT-005 … API-INT-008; with eight API blocks the backend plan's SVC-API phase reached its split threshold and now splits into SVC-API-COMMAND (the four writes) and SVC-API-QUERY (the four reads), so the unit `SVC-API` no longer exists. ADR-INT-021 binds every screen read to INT's operations, so the frontend mock serves `api-spec-int.yaml` only. ADR-INT-019 had derived 43 backend ACs and named a mock serving four documents. TC-INT-001 … TC-INT-086 were written in the same uncommitted P4 run.
Decision    : (1) The eight new ACs observe API responses, so each yields one backend case, TC-INT-087 … TC-INT-094 (continuing the sequence; no id is renumbered); the refusals (AC-INT-068, AC-INT-070, AC-INT-074) sit in RULE-SCENARIOS, the others in API-SCENARIOS; each names SVC-API-QUERY as its package. (2) Every backend case that named SVC-API names SVC-API-COMMAND; PORTS and XM-INT-001 cases are unchanged. (3) Frontend cases exercise INT's reads by id (API-INT-005 … API-INT-008) against the mock server serving `api-spec-int.yaml`; a failing read is INT's own INT-500 (the owners' read codes are no longer seen by the frontend). (4) Counts: backend 52 cases (51 ACs + XM-INT-001), frontend 42 cases (23 ACs, 3 frontend cases of backend ACs, 16 UXD cases); AC coverage 74/74. ADR-INT-019 (2), (3), (4) and (6) stay in force.
Consequences: Every unit with tests of both execution plans (PORTS, SVC-API-COMMAND, SVC-API-QUERY, XM-INT-001; F1–F4 × 5 screens) is named by ≥1 case. TC-INT-091 needs Document Access's in-process listing operation delivered (ADR-INT-020 (4)). Non-breaking.
