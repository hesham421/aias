### SUB PORTS-QUERY
- `DocumentSourceQueryPort` (port) — `run(sqlText, inputName, requestNumber, connectionSettings, maxRows, deadline) → rows[{documentType, location | content}]`. Contract: the SQL text is sent **exactly as stored** (REQ-DOC-051); the request number is passed as ONE bound value under the parameter `:{inputName}`, never concatenated (REQ-DOC-004, REQ-DOC-012; AIAS-5); the limit `maxRows + 1` is requested so that an over-limit result is detected and never truncated silently (REQ-DOC-039).
- `McpDocumentSourceAdapter` (adapter, `path` mode) — calls the platform MCP query channel (the injected query-executor bean of the platform track — ADR-DOC-001) with the bound value and the row limit; it requests the type and path columns only, so the MCP channel never carries document content (REQ-DOC-016; G14).
- `JdbcDocumentSourceAdapter` (adapter, `blob` mode) — opens a read-only JDBC session on the `jdbc` connection's settings (`connection.setReadOnly(true)`, credential resolved from the environment's secret store by its reference), prepares the statement, binds the request number, sets `maxRows + 1` and the remaining Check time as the query timeout, and streams each content column through `Blob.length()` first and `getBinaryStream()` only when the size is within the limit (REQ-DOC-012, REQ-DOC-013, REQ-DOC-041).
- Guards run **before** any query (connection settings read through XM-DOC-004):
  - RULE-DOC-006 — `blob` documents only over a jdbc connection · trigger: on fetch, before the document source query runs · statement: The system shall refuse to run a `blob` document source query whose named connection is not of type `jdbc`. · message (en): The documents of "{serviceCode}" could not be fetched: connection "{connectionName}" is not a JDBC connection. · message (ar): PENDING ADR-DOC-012 · effect: every required document type → UNREADABLE / SOURCE_QUERY_FAILED with the message as detail (REQ-DOC-014).
  - RULE-DOC-007 — Document source query only over a read-only connection · trigger: on fetch, before the document source query runs · statement: The system shall refuse to run a document source query whose named connection is not declared read-only. · message (en): The documents of "{serviceCode}" could not be fetched: connection "{connectionName}" is not declared read-only. · message (ar): PENDING ADR-DOC-012 · effect: every required document type → UNREADABLE / SOURCE_QUERY_FAILED (REQ-DOC-052).
- A query error, a timeout or more than `maxRows` rows → every required document type UNREADABLE / SOURCE_QUERY_FAILED with the error in the detail (REQ-DOC-039, ADR-DOC-007).
